=>(gemini):(intento 3)
    El problema: Tienes asignado location=proyecto-evidencia.mp4. Como el objetivo es grabar video de forma segmentada, el sistema necesita generar múltiples archivos.
    Si no le indicas un contador en el nombre, no sabrá cómo nombrar el segundo archivo y el pipeline podría colapsar.
    (coincide con el laboratorio)
    
    La solución: Debes agregar un patrón de formato numérico como %02d en el parámetro location para que el sistema enumere los cortes (ej. 00, 01, 02). 
    
    El problema: En la segunda rama, el video entra a timeoverlay directamente desde la cola (queue). Si timeoverlay no soporta la manipulación directa sobre el formato I420 dictado por el tee,
    provocará un error interno de datos (Internal data stream error o can't handle caps).  
    La solución: La regla de depuración de GStreamer establece que cuando un enlace falla por manipulación de imagen, casi siempre falta un videoconvert. Es más seguro colocar videoconvert 
    antes de timeoverlay para que GStreamer negocie automáticamente el espacio de color que el texto necesita.

Efectivamente, eliminar el videoconvert empeoró la situación.
El elemento videoconvert sirve únicamente para transformar formatos de color (como de I420 a GRAY8).  Sin embargo, estabas intentando reducir la resolución original 
de 640x480 a 160x120. Para modificar dimensiones, GStreamer exige explícitamente el uso del elemento videoscale

Al eliminar por completo el videoconvert, creaste lo que el laboratorio llama un "contrato imposible".  La bifurcación (tee) está entregando video en formato I420.
Inmediatamente después de la cola (queue), pusiste un filtro exigiendo GRAY8.Como no hay ningún elemento en el medio capaz de hacer la traducción matemática de color,
el pipeline colapsa antes de arrancar. La regla es clara: cuando un enlace falla por formato, casi siempre falta un videoconvert o un videoscale.(sherman):videoconvert


Aunque tu aplicación final en Python (appsink) recibirá felizmente el formato GRAY8 (un byte por píxel) para analizar la luminancia, el elemento de prueba autovideosink
necesita dibujar eso en el monitor de tu computadora. Muchas tarjetas gráficas y gestores de ventanas no aceptan GRAY8 crudo para visualización en pantalla.
